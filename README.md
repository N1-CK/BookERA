# BookERA

Android-приложение для поиска книг, личной библиотеки и чтения FB2, EPUB, PDF и TXT.

## Запуск

Откройте проект в Android Studio с JDK 17 и Android SDK 35. Сборка: `./gradlew :app:assembleDebug`. В проекте используются Gradle 8.9 и AGP 8.7.3. Для установки не нужны API-ключи: Open Library и Gutendex доступны без них. Интернет нужен для поиска, обложек и скачивания; импортированные книги и чтение работают локально.

## Как пользоваться

- Ищите книгу по названию или автору на экране библиотеки. Поиск обращается к Open Library, Project Gutenberg через Gutendex и существующему модулю Флибусты. Найденные книги сохраняются в локальном каталоге.
- Откройте карточку и выберите доступное издание. Open Library используется для метаданных и обложек; наличие записи там **не означает**, что PDF или EPUB можно скачать. Gutendex отдаёт ссылки на свободные EPUB/TXT. Модуль Флибусты может быть недоступен из-за ограничений сайта.
- Кнопка «Добавить книгу» открывает системный выбор файлов. Поддерживаются FB2, EPUB, PDF до 80 МБ и TXT до 10 МБ. Файл копируется в хранилище приложения. Свайп вправо добавляет книгу в избранное; влево предлагает удаление.
- EPUB/TXT: свайп страниц, оглавление, закладки, выделение текста, шрифт, размер и три цветовые темы; страница чтения сохраняется. PDF: свайп страниц, масштабирование, быстрый переход по ползунку, сохранение страницы. FB2 использует существующую читалку.

## Бесплатные источники

| Источник | Использование | Ограничения |
| --- | --- | --- |
| Open Library | Поиск метаданных и обложек, без ключа | Не выдаёт произвольную скачиваемую книгу по ISBN или Work ID. Отсутствующую обложку показываем как локальную заглушку. |
| Project Gutenberg через Gutendex | Поиск и скачивание свободных EPUB/TXT, без ключа | Проверяйте статус произведения в вашей стране; в каталоге могут быть книги без пригодного EPUB/TXT. |
| Standard Ebooks | Возможный следующий модуль через официальный OPDS `https://standardebooks.org/feeds/opds` | Сейчас не интегрирован; EPUB можно скачать вручную и импортировать. Каталог в основном англоязычный. |
| Флибуста | Существующий модуль поиска ссылок | Работоспособность зависит от доступности сайта; права на скачивание зависят от книги и региона. |

Обложки сначала берутся из метаданных Open Library (Cover ID, затем ISBN). Для записей без обложки приложение делает ограниченное число запросов по названию и автору, сохраняет найденные ссылки. Импортированный EPUB может предоставить собственную обложку. Неизвестная обложка показывается как карточка с инициалом. Ключ и платный сервис для этого не требуются.

## Границы текущей читалки

EPUB извлекает текст глав из XHTML и отображает его в нативных страницах. Сложная верстка, таблицы, встроенные иллюстрации и CSS EPUB пока не воспроизводятся. Страницы разбиваются по объёму текста и могут прокручиваться внутри; визуального трёхмерного загиба страницы нет. PDF сохраняет исходное расположение элементов и рендерит одну страницу за раз; размер шрифта PDF менять нельзя. TXT читает UTF-8, UTF-16 с BOM и Windows-1251 как запасной вариант. Профиль сейчас локальный, без регистрации и синхронизации.
