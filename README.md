# BookERA

Android-библиотека с чтением FB2, EPUB, TXT и PDF.

## Сборка

Проверенная по таблице совместимости связка: Android Gradle Plugin **8.7.3**, Gradle **8.9**, **JDK 17**. Compile SDK — 35.

В Android Studio откройте **Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK** и выберите установленный **JDK 17** (при необходимости Download JDK → 17). После этого выполните Sync Project with Gradle Files.

Для терминала установите `JAVA_HOME` на каталог JDK 17:

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

В `gradle/gradle-daemon-jvm.properties` закреплён JDK 17. `jvmToolchain(17)` задаёт компилятор, но сам по себе не меняет JVM, на которой запускается Gradle. Java 25 поддерживается для запуска Gradle начиная с 9.1; замена только `distributionUrl` не обновляет Android/Kotlin/KSP-плагины. Не меняйте wrapper на 9.x отдельно от согласованного обновления этих плагинов.

Официальные таблицы: [AGP 8.7](https://developer.android.com/build/releases/agp-8-7-0-release-notes), [Gradle и Java](https://docs.gradle.org/current/userguide/compatibility.html).

## Чтение

- Кнопка **Aa**: четыре шрифта, размер 12–36, светлая/сепия/тёмная бумага, горизонтальное или вертикальное листание. Настройки сохраняются.
- Долгое нажатие на текст → выделите нужную фразу → **Сохранить цитату**. Сохранённые фразы подсвечиваются и после изменения размера шрифта.
- Закладка сохраняет место в исходном тексте, а не номер страницы. Оглавление, поиск и переход к странице доступны на нижней панели.
- **Профиль → Закладки и цитаты → К месту в книге** открывает сохранённое место; запись можно удалить.
- В PDF доступны оба направления листания, закладки и масштабирование. PDF отображается как документ с фиксированной вёрсткой: смена шрифтов и текстовые цитаты доступны в FB2/EPUB/TXT.

## Библиотека и поиск

Импорт находится в профиле. На главном экране нет плавающей кнопки добавления. Тема приложения выбирается в профиле: авто, светлая, тёмная.

Кнопка фильтров рядом с поиском задаёт поле запроса (везде/название/автор), дополнительного автора и год публикации. Фильтры действуют для всех вкладок и каталогов. При выборе года книги без известного года исключаются; Open Library сообщает год первой публикации, другие каталоги могут его не предоставлять.

Каталоги опрашиваются одновременно и публикуют результаты по мере готовности. Старые HTTP-запросы отменяются при новом поиске. Обложки не задерживают выдачу, PDF-страницы и последняя текстовая разметка кешируются, фильтрация и разметка выполняются вне главного потока.

Обновление базы 5 → 6 сохраняет книги и добавляет таблицу заметок. Старые закладки из настроек переносятся один раз.
